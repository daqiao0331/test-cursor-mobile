# test-cursor-mobile

一个用于测试 Cursor 移动端开发的示例项目。

A sample project for testing mobile development with Cursor.

## 如何运行 (How to Run)

### 前置要求 (Prerequisites)

在运行此项目之前，请确保您已安装以下工具：

Before running this project, please ensure you have the following tools installed:

- Git
- Node.js (推荐版本 / Recommended version: 16.x 或更高 / or higher)
- npm 或 yarn (包管理器 / Package manager)

### 克隆项目 (Clone the Repository)

```bash
git clone https://github.com/daqiao0331/test-cursor-mobile.git
cd test-cursor-mobile
```

### 安装依赖 (Install Dependencies)

```bash
npm install
# 或者使用 yarn / Or use yarn
yarn install
```

### 运行项目 (Run the Project)

#### 开发模式 (Development Mode)

```bash
npm run dev
# 或者 / Or
yarn dev
```

#### 生产构建 (Production Build)

```bash
npm run build
# 或者 / Or
yarn build
```

#### 启动生产服务器 (Start Production Server)

```bash
npm start
# 或者 / Or
yarn start
```

### 测试 (Testing)

```bash
npm test
# 或者 / Or
yarn test
```
