# Serene · 静观

> 冥想放松的全屏视觉程序 —— 算法生成的无限动画，与你自己的 4K 风景视频。

基于 Electron（HTML / CSS / JavaScript）。
界面遵循一套极简色板：炭黑背景、象牙白文字、陶土色点缀，全程无多余元素；
画面之外没有任何常驻 UI，也不显示视频文件名。

## 视觉源

### 算法动画（内置，时长无限，永不重复）

| 场景 | 类型 | 描述 |
|---|---|---|
| 极光 AURORA | 着色器 | 三层极光帷幕在山脊剪影上方流动 |
| 黎明海面 OCEAN DAWN | 着色器 | 日出海面，波光沿反射路径闪烁 |
| 月下云海 MOONLIT MIST | 着色器 | 月光下缓慢漂移的层层雾海 |
| 深空星云 NEBULA | 着色器 | 域扭曲星云缓慢旋转漂移 |
| 生命游戏 CONWAY LIFE | 元胞自动机 | 一格一格无限迭代的生灭图案，自动补种永不死寂 |
| 螺旋元胞 CYCLIC CA | 元胞自动机 | 状态相互追逐，自发形成主题色的流动波纹 |
| 初等元胞 RULE 90 | 元胞自动机 | 谢尔宾斯基三角逐行生长，向上无限滚动 |

着色器场景由 GPU 逐帧计算，分辨率无关（4K 屏即原生 4K）；
元胞自动机逐格迭代、随机播种，永远不会陷入循环。

### 视频（可选）

- 自动扫描程序旁的 `videos/` 文件夹（免费 4K 素材获取见 [videos/README.md](videos/README.md)）
- 菜单里"＋ 本地视频文件"任选硬盘上的视频
- 粘贴网络视频直链，自动记住

一段播完自动切到下一项；算法动画停留 3 分钟后自动轮换（按 `L` 可停留在当前画面）。

## 呼吸引导（按 B）

中央 HUD 引导 4-7-8 呼吸法：吸气 4 秒 → 屏息 7 秒 → 呼气 8 秒。
呼吸圆随气息胀缩，外圈 60 格刻度实时点亮显示相位进度，中心倒计时秒数；
三个相位各有配色：吸气·青苔绿，屏息·象牙白，呼气·陶土色。

## 快捷键

| 键 | 功能 | 键 | 功能 |
|---|---|---|---|
| `M` | 视觉源菜单 | `空格` | 暂停 / 继续 |
| `→` `←` | 下一个 / 上一个 | `L` | 停留（不自动切换） |
| `B` | 呼吸引导 | `S` | 声音开关（默认静音） |
| `F` | 全屏切换 | `Q` | 退出 |

## 运行（开发模式）

```bash
# 需要 Node.js 18+
npm install
npm start
```

无需任何素材即可使用——算法动画开箱即有画面。

## 打包成 Windows exe

```bash
npm install
npm run dist
```

`dist/` 目录会生成两种产物，任选其一：

| 产物 | 说明 |
|---|---|
| `Serene 1.0.0.exe`（portable） | **绿色单文件版**：无需安装，拷到任何电脑双击即用 |
| `Serene Setup 1.0.0.exe`（nsis） | 安装向导版：生成开始菜单与桌面快捷方式 |

打包说明：

1. **视频不打进 exe** —— `videos/` 文件夹放在 exe 同级目录即可，换素材不用重新打包。
2. 自定义图标：项目根目录放 `build/icon.ico`（256×256）。
3. 建议直接在 Windows 上执行 `npm run dist`（macOS / Linux 交叉打包需要 wine）。
4. 对方电脑无需安装 Node.js，双击 exe 即可运行。

## 技术

- Electron + 原生 `<video>` 双层交叉淡化（视频硬件解码，4K 无压力）
- WebGL2 片元着色器（风景场景）+ Canvas 2D（元胞自动机）
- 渲染进程零依赖、零框架：`renderer/` 下三个文件 + 一个场景库
