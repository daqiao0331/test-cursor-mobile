# videos/ —— 4K 实拍风景目录

把从下面网站下载的**免费 4K 风景视频**（mp4 / mov / webm / mkv）直接放进这个文件夹，
程序启动时会自动把它们加载为额外场景（需要安装 `opencv-python`）。

推荐免费素材站（均可商用、无需署名，下载时选 4K / 2160p）：

| 网站 | 地址 | 推荐搜索词 |
|---|---|---|
| Pexels Videos | https://www.pexels.com/videos/ | `4K nature`, `ocean aerial`, `aurora` |
| Pixabay | https://pixabay.com/videos/ | `4K landscape`, `waterfall`, `clouds timelapse` |
| Mixkit | https://mixkit.co/free-stock-video/nature/ | `forest`, `sunset`, `mountains` |
| Coverr | https://coverr.co/ | `calm`, `sea`, `sky` |
| NASA 影像库 | https://images.nasa.gov/ | `earth 4K`, `nebula`, `ISS timelapse` |

建议挑选：运动缓慢、无剪辑跳切、无人物的长镜头（航拍海面、云海延时、极光、星空），
最贴合冥想场景。
