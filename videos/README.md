# videos/ —— 4K 风景视频目录

把从下面网站下载的**免费 4K 风景视频**（mp4 / webm / mov / mkv）直接放进这个文件夹，
程序启动时自动加载；也可以在程序里按 `M` 打开菜单点"刷新"。

打包成 exe 后，把这个文件夹放在 `Serene.exe` 旁边即可，换素材不用重新打包。

推荐免费素材站（均可免费使用，下载时选 4K / 2160p）：

| 网站 | 地址 | 推荐搜索词 |
|---|---|---|
| Pexels Videos | https://www.pexels.com/videos/ | `4K nature`, `ocean aerial`, `aurora` |
| Pixabay | https://pixabay.com/videos/ | `4K landscape`, `waterfall`, `clouds timelapse` |
| Mixkit | https://mixkit.co/free-stock-video/nature/ | `forest`, `sunset`, `mountains` |
| Coverr | https://coverr.co/ | `calm`, `sea`, `sky` |
| NASA 影像库 | https://images.nasa.gov/ | `earth 4K`, `ISS timelapse` |

挑选建议：运动缓慢、无剪辑跳切、无人物的长镜头（航拍海面、云海延时、极光、星空），
最贴合放松与冥想。
